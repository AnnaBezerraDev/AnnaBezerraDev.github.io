Sou Anna Luiza Bezerra, desenvolvedora de software sediada em Barretos - SP. Minha atuação combina a solidez e a tipagem forte de C# (.NET 10) com a agilidade do ecossistema moderno de JavaScript / TypeScript (React & Node.js) e a precisão do Python para manipulação de dados e IA.
